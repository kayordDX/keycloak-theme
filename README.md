# Keycloak Theme

This is the keycloak theme used for kayord.

## This is based on keycloakify shadcn theme

https://docs.keycloakify.dev/starter-themes/shadcn-ui-tailwind

## Build Theme

```bash
pnpm build-keycloak-theme

cp dist_keycloak/keycloak-theme-for-kc-all-other-versions.jar ../online/container/keycloak/themes/.
```
